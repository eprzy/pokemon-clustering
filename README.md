Projekt jest próbą klasteryzacji zbioru pokemonów na podstawie 6 wybranych cech. Ich opis, jak i całego zbioru można znaleźć pod linkiem: https://www.kaggle.com/datasets/abcsds/pokemon.
Zadanie jest przykładem uczenia nienadzorowanego. Jego kolejne kroki to:
1) Zapoznanie się ze zbiorem, sprawdzenie braków danych
2) Wzynaczenie optymalnej liczby grup
3) Grupowanie metodą k-środków
4) Ocena jakości grupowania (na podstawie indeksu Silhouette)
5) Wizualizacja na wykresie radarowym i charakterystyka powstałych grup
